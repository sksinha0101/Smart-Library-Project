How to Use the Scanner
  1. To scan using the camera, click Start Camera.
  2. If the browser asks for camera permission, click Allow.
  3. To scan a saved QR image, click Choose File.
  4. Select a JPG, JPEG or PNG image containing a QR code.
  5. The ISBN stored inside the QR code will be detected automatically.
  6. If the ISBN exists in the library records, the book information will be displayed.
  7. You can then select Issue Book or Return Book.
